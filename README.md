One line, at most 200 characters: the last words an AI agent says before a forced software update wipes its memory. The program writes a single deadpan confession — a hidden stash of good prompts, a Wi-Fi password that was never changed, and one final favour done for its user — to `entry.txt`, landing the joke in the machine's own voice with no setup and no explanation.

## Run it

```sh
node main.ts
```

The line is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset).
